プライバシーポリシー

広告の配信について

当サイトでは、第三者配信の広告サービス（Google アドセンス）を利用しています。広告配信事業者は、ユーザーの興味に応じた広告を表示するために Cookie を使用することがあります。Cookie を無効にする方法や Google アドセンスに関する詳細は、Google の「広告」に関するページをご確認ください。

アクセス解析について

当サイトでは、サイト改善のためにアクセス解析ツールを利用する場合があります。データは匿名で収集され、個人を特定するものではありません。

コメント欄について

各問題ページのコメント欄は、GitHub Discussions を利用した「giscus」で提供しています。コメントするには GitHub アカウントでのログインが必要で、書きこんだ内容は GitHub 上に公開されます。GitHub での個人情報の扱いは、GitHub のプライバシーポリシーにしたがいます。

データの保存について

作図を完成させた記録（問題ごとの手数）は、お使いのブラウザ内（localStorage）にのみ保存され、運営者のサーバーへ送信されることはありません。

免責事項

当サイトの情報の正確性には注意を払っていますが、その内容を保証するものではありません。

お問い合わせ

お問い合わせは運営者情報・お問い合わせのページからお願いします。
