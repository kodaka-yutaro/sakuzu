直角の三等分の作図

未AC問題 6 / 50基本の作図難しさ ★★☆☆☆ 基本

問題：直角∠AOB を3等分する2本の直線を作図しましょう。

道具を選んで、点をタップ（クリック）して作図します。線や円の交点は自動で点になります。何もない所をドラッグすると図を動かせます。

作図の手順

手順を表示する（ネタバレ注意）
  1. Oを中心に、Aを通る円をかきます。この円はBも通ります。
  2. Aを中心に、Oを通る円をかき、最初の円との交点（上側）をPとします。
  3. Bを中心に、Oを通る円をかき、最初の円との交点（右側）をQとします。
  4. OとPを結びます。
  5. OとQを結べば、直角が3等分されます。

なぜこれで作図できるのか

解説を表示する（ネタバレ注意）

OA = OP = AP なので三角形OAPは正三角形で、∠AOP = 60° です。だから ∠POB = 90° − 60° = 30° です。

同じように三角形OBQも正三角形なので ∠BOQ = 60°、∠AOQ = 30° です。よって ∠AOQ = ∠QOP = ∠POB = 30° となり、直角が3等分されます。

豆知識

どんな角でも3等分できる作図法は存在しません。直角が3等分できるのは、30° という角がたまたま作図できるからです。たとえば60° の角は3等分できません（20° が作図できないため）。作図できない問題もどうぞ。
